🎯 MỤC TIÊU TỔNG QUAN
──────────────────────────────────────────────────────────────────────────────────
Xây dựng trang web đọc truyện tranh mobile-first, cho phép nhập URL từ
nhattruyenqq.com, tự động crawl nội dung (hình ảnh chương truyện) và hiển thị
giao diện đọc truyện mượt mà với infinite scroll tự động load chương tiếp theo.

📐 Giao diện tham khảo: image_base.png (Comic Reader App UI)
🛠  Tech Stack: Next.js 16 + Tailwind v4 + ShadcnUI + Tabler Icons
💾 Database: localStorage (tạm thời)

PHASE 1: BACKEND - API PROXY/CRAWL ✅ HOÀN THÀNH
================================================================================
Ngày hoàn thành: 2026-02-17

1.1 ✅ API Route: /api/crawl (app/api/crawl/route.ts)
    - POST request nhận URL chương truyện
    - Dùng cheerio để parse HTML
    - Trích xuất: title, chapterNumber, chapterTitle, images[], nextChapterUrl
    - Multiple fallback selectors cho images
    - Error handling + timeout 15s

1.2 ✅ API Route: /api/proxy-image (app/api/proxy-image/route.ts)
    - GET request với query param ?url=
    - Proxy ảnh với Referer header phù hợp
    - Stream response trực tiếp (ArrayBuffer)
    - Cache-Control: max-age=86400
    - Timeout 30s

1.3 ❌ API Route: /api/comic-info (BỎ QUA - không cần cho MVP)

📦 Dependencies đã cài:
    - cheerio (HTML parser)
    - sonner (Toast notifications)

PHASE 4: XỬ LÝ KỸ THUẬT ✅ HOÀN THÀNH
================================================================================
Ngày hoàn thành: 2026-02-17

4.1 ✅ CORS & Hotlink Protection
    - API proxy-image xử lý hoàn toàn
    - Mọi ảnh đi qua /api/proxy-image?url=<encoded>
    - Referer header tự động detect từ image URL

4.2 ✅ Rate Limiting & Throttling
    - 800ms delay giữa các request crawl chương
    - loadingRef để prevent duplicate requests
    - Chỉ crawl khi user scroll gần tới (IntersectionObserver rootMargin: 600px)

4.3 ✅ Performance Optimization
    - Lazy loading ảnh (loading="lazy" cho index > 2)
    - Skeleton placeholder khi ảnh đang tải
    - requestAnimationFrame cho scroll direction
    - passive: true cho scroll listeners
    - decoding="async" cho images

4.4 ✅ Error Handling
    - URL validation trước khi submit
    - Retry button cho chương lỗi
    - Retry button cho ảnh lỗi
    - Error messages tiếng Việt rõ ràng
    - Timeout cho fetch requests (15s crawl, 30s image)
